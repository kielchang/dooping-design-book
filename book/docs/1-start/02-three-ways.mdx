# 三種取用方式

三種可以混用，**不必全有全無**。

<FlowThreeWays />

（圖只是導覽；三種方式的內容與判準見下文。）

## 方式一：只讀規範（零相依）

最輕的用法。讀 [基礎](/foundations)、[模式](/patterns)、[無障礙](/accessibility)，
用你自己的技術棧實作。適合：

- 已經有一套元件庫，只想統一「操作邏輯」
- 不是 React（Vue / Svelte / Blazor / 原生）
- 只想解決一個具體問題（例如「送出前的變更摘要該長怎樣」）

模式章每一則都可以直接當規格書用。

## 方式二：registry 複製元件（推薦）

把元件**原始碼**複製進你的專案。之後它就是你的程式碼。

```bash
# 一次裝一個
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/data-table.json

# 相依會自動一起裝（DataTable 會帶上 table / input / button / select / tooltip / utils…；完整清單見 /r/data-table.json）
```

安裝後的落點：

```
src/
├── components/dooping/    ← 元件
└── lib/dooping/           ← 工具（cn、useSort、useDialogState、useTableUrlState、nav、csv、download、forms-diff）
```

:::note 前置條件
你的專案要有 `components.json`（shadcn 的設定檔）與 `@/*` 路徑別名。
還沒有的話先跑一次 `npx shadcn@latest init`。
:::

## 方式三：安裝 token 套件（唯一建議的硬相依）

```bash
npm install @dooping/tokens
```

**Tailwind v4（建議）**——全域 CSS 四行，**順序不能改**：

```css title="你的全域 CSS"
@import "tailwindcss";
@import "tw-animate-css";
@import "@dooping/tokens/tokens.css";   /* 值 */
@import "@dooping/tokens/tailwind.css"; /* token → utility 名稱對映 */
```

從 `npx shadcn init` 起手的話，**刪掉**它產生的 `:root`／`.dark` 色值區塊、
`@theme inline` 裡的 `--color-*` 對映與 `@custom-variant dark`。

**Tailwind v3**：

```js title="tailwind.config.js"
module.exports = {
  presets: [require("@dooping/tokens/tailwind-preset")],
  content: ["./src/**/*.{ts,tsx}"],
};
```

```css title="你的全域 CSS"
@import "@dooping/tokens/tokens.css";
```

兩個版本產出的 class 名稱逐字相同（`bg-danger-subtle`、`h-control`、`duration-fast`…），
元件原始碼不必分版。

沒有用 Tailwind 也可以——`tokens.css` 是純 CSS 變數，任何宿主都吃得下：

```css
.my-alert {
  background-color: hsl(var(--danger-subtle));
  border: 1px solid hsl(var(--danger) / 0.3);
  border-left: 4px solid currentColor;
  color: hsl(var(--danger-subtle-foreground));
}
```

需要在 JS 裡拿值（Canvas 圖表、伺服器端產 PDF、Figma plugin）：

```ts
import { semanticColors, chartColors } from "@dooping/tokens";

const palette = chartColors("dark");   // ["#66a3f4", "#7e6f00", …]
const colors = semanticColors();        // { primary: "222.2 47.4% 11.2%", … }
```

## 該選哪一種

  </Do>

既有系統的導入節奏見 [治理 → 導入三階段](/governance/adoption)；
**全新專案**裝完 token 與元件之後，從[頁面章](/pages)選頁型開始規劃畫面
（每種頁型都附骨架、行為規範與最小安裝集）；
上線之後怎麼跟著規範演進，見[跟上新版](/governance/staying-current)。
