# 字級與排版

**只有 7 階。** 層次靠「字重＋顏色」分，不靠增加字級。

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `micro` | 10px | 徽章內文字、極次要註記 |
| `tiny` | 11px | 欄位說明、圖例 |
| `xs` | 12px | 表格次要欄、標籤 |
| `sm` | **14px** | **介面預設字級** |
| `base` | 16px | 內文 |
| `lg` | 18px | 卡片標題 |
| `xl` | 24px | 頁面標題 |

## 預設 14px，內文型頁面 16px

介面預設 14px（表格與表單）；內文型頁面（說明、公告）用 16px。

## 數字一律等寬

```jsx
<td className="text-right tabular-nums">1,284,000</td>
```

## 負值用會計括號

金額負值顯示為 `($2,000)` 而不是 `-$2,000`。紅字可以加，但不是唯一線索：
灰階列印時要靠括號讀出負值。

## 顯示不四捨五入

格式化函式一律 `maximumFractionDigits: 10`，顯示層**不偷偷進位**。
要進位請在計算層明確進位。

## 字體

```css
--font-family-sans: ui-sans-serif, system-ui, -apple-system, "Segoe UI",
                    "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", sans-serif;
```

用系統字體堆疊，不載自訂字體。
