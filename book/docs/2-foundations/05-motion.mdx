# 動態

**動畫只用來讓狀態變化被看見**，不做裝飾。

| Token | 值 | 用在哪 |
| --- | --- | --- |
| `duration-instant` | 0ms | reduced-motion 的降級目標 |
| `duration-fast` | **150ms** | 顏色／透明度回饋（hover、focus） |
| `duration-normal` | 200ms | 浮層出現、展開收合 |
| `duration-slow` | 1500ms | 循環式引導脈動（唯一允許的長動畫） |

<Rules>
  <Do>
    <p>互動回饋一律 <strong>150ms</strong>。</p>
  </Do>
  <Dont>
    <p>不要用 300ms 以上的轉場。</p>
  </Dont>
</Rules>

## 唯一的長動畫：聚光脈動

引導與文件示意共用的 `.spotlight-ring` 是 1.5 秒的呼吸式外擴光暈，**循環**播放，
用來持續把視線拉到「該點這裡」。

## prefers-reduced-motion 是必須，不是加分

```css
@media (prefers-reduced-motion: reduce) {
  .spotlight-ring {
    animation: none;
    /* 降級成靜態環——訊息不能消失，只是不動 */
    box-shadow: 0 0 0 3px hsl(var(--primary)), 0 0 0 6px hsl(var(--primary) / 0.3);
  }
}
```

降級**不是把效果拿掉，是換成靜態版本**：`animation: none` 之後必須補上靜態樣式。

列印樣式同樣印靜態環。
