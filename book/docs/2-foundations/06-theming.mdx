# 深淺主題

## 兩種宿主鉤子，同時支援

```css
.dark,
[data-theme="dark"] {
  --background: 222 22% 8%;
  /* … */
}
```

- `.dark` class —— Tailwind / shadcn 生態的慣例
- `[data-theme="dark"]` 屬性 —— Docusaurus、多數文件站與部分後台框架的慣例

## 切換要掛在 `documentElement`

```ts
document.documentElement.classList.toggle("dark", isDark);
document.documentElement.setAttribute("data-theme", isDark ? "dark" : "light");
```

  </Do>
  <Dont>
    <p>不要只切在某個 wrapper <code>&lt;div&gt;</code> 上。</p>

## 深色是設計出來的，不是算出來的

深色 token **不是**淺色的反轉：不做機械式反轉亮度；沿用同色相、壓低飽和度、建立表面抬升階。

這套 token 的深色沿用淺色的冷靛藍色相，飽和度從 84% 壓到 16–22%，
並建立五級表面抬升。每個值都對深色實際背景重新驗對比，不沿用淺色的數字。

:::warning 對比要在真正的背景上驗
對實際頁面背景（`#101319`）驗，不對色票研究時常用的比較背景（例如 `#020817`）驗。
背景換了，對比結果就要重跑（做法見[色票配色策略](/foundations/choosing-a-palette#背景改版之後驗證結果全部作廢)）。
:::

## 圖表色票是兩組獨立的值，不是「有幾色不一樣」

淺深兩組分類色票**不得共用值**。

```ts
import { chartColors } from "@dooping/tokens";

chartColors("light"); // 8 色，L* 落在 30–62
chartColors("dark");  // 另外 8 色，L* 落在 49–86 —— 沒有任何一色與淺色相同
```

（守衛：`npm run verify:color`，淺深出現共用值就不合格；分類色票的規則見 [色彩語意](/foundations/color)）

## 環境色主題

深／淺是**明度**的兩種模式，環境色主題是另一個維度。兩者正交，可以任意組合。

```html
<html data-theme="dark" data-color-theme="teal">
```

- `data-theme` / `.dark` —— 明暗，既有機制不變
- `data-color-theme` —— 環境色，**不設就是預設主題（石墨）**

**主題只換外殼。** 側欄與頂列合起來是一個 L 形的大區塊，主題只換這一塊的底色，
用顏色讓人一眼認出目前在哪個工作環境。內容區（畫布、卡片、浮層、欄位、表格）一律中性、所有主題同值。
有哪些色、各自的色彩學語意，見[環境色票](/foundations/environment-palette)。

### 主題影響哪些 token

環境主題只宣告**外殼的 9 個鍵**：

| Token | 意思 |
| --- | --- |
| `--sidebar` | 外殼底色（側欄與頂列） |
| `--sidebar-foreground` | 外殼上的文字 |
| `--sidebar-muted-foreground` | 外殼上的次要文字（群組標題等） |
| `--sidebar-border` | 外殼內的分隔線 |
| `--sidebar-accent` ／ `-foreground` | 選中的側欄項：同色相亮一階 |
| `--sidebar-primary` ／ `-foreground` | 外殼上的標誌塊：與外殼反相 |
| `--sidebar-ring` | 外殼上的聚焦環 |

**與主題無關的**：內容面的中性色、`--primary`、`--brand` 家族（所有主題都鏡射 `--primary`）、
`--ring`、全部狀態色與提醒淡底、全部圖表色票。
（守衛：`npm run verify:color`。環境主題覆蓋外殼以外的鍵、或 brand 沒有鏡射 primary，就不合格。）

### 色相預算：主題色只進外殼

| 介面層 | 跟著主題變？ | 載體 |
| --- | --- | --- |
| 外殼（側欄＋頂列）的大區塊底色 | ✅ | `--sidebar` 家族 |
| 內容面（畫布、卡片、浮層、欄位） | ❌ | 中性色，所有主題同值 |
| 動作（確認／送出／儲存） | ❌ | `--primary` 中性近黑 |
| 品牌按鈕（`variant="brand"`，已淘汰） | ❌ | `--brand` ≡ `--primary` |
| 互動（hover／pressed／已選） | ❌ | `currentColor` 疊加，機制無色相 |
| 聚焦環 | 只在外殼換成淺色環 | 內容區 `--ring`；外殼 `--sidebar-ring` |
| 狀態／提醒色 | ❌ | 語意固定，見[提醒色辭典](/foundations/alert-colors) |
| 資料（圖表 8 色） | ❌ | 全主題共用 |

按鈕、提醒、琥珀欄位都靠顏色傳達意思，它們全部坐在內容面上——主題色碰不到它們，
外殼的顏色再強烈也不會被讀成「錯誤」或「已改動」。

### 外殼上的元件：`on-shell`

頂列與側欄的內容區塊套了 `on-shell`（`AppShell` 的頂列、`SidebarHeader`／`SidebarContent`／`SidebarFooter` 已內建）。
這一層把 `--background`、`--foreground`、`--muted-foreground`、`--border`、`--input`、`--ring`
換成外殼的值，放進來的一般元件（ghost／outline 按鈕、分隔線、輸入框、聚焦環）自動改用外殼上看得清楚的顏色。
浮層（下拉、對話框）走 portal 掛到 body，維持內容面的中性色。

<Rules>
  <Do>
    <p>頂列上的按鈕用 <code>ghost</code> 或 <code>outline</code>；標誌塊與頭像用 <code>bg-sidebar-primary text-sidebar-primary-foreground</code>。</p>
  </Do>
  <Dont>
    <p>不要在外殼上用 <code>bg-primary</code>、<code>bg-brand</code> 做色塊——深色外殼上會變成黑底黑塊。</p>
  </Dont>
</Rules>

**外殼上的狀態徽章要加外圈。** 通知數、紅點直接疊在深色外殼上，對比只有 2:1 上下，看不見。
一律加 `ring-2 ring-sidebar-foreground`：外圈是外殼的字色，紅點對外圈 ≥ 3:1。

### 主題島

`data-color-theme` 也可以放在任何元素上，只換那個元素底下的外殼鍵。
應用切換清單用它畫「那個系統的外殼色」縮影（`NavLeaf` 的 `colorTheme`）：

```tsx
<span data-color-theme="teal" className="bg-sidebar text-sidebar-foreground ring-1 ring-sidebar-foreground/30">文</span>
```

每個主題（含預設）都有淺色與兩種後代深色選擇器，頁面的 `.dark` 在 `<html>` 上、主題屬性在元素上也成立。
（守衛：`tests/environment-theme.test.ts`。）

整頁的主題仍然掛在 `<html>`：浮層走 portal 掛到 body，包在 wrapper 上的主題抓不到它們。
主題島只用在色塊、色票這種局部預覽。

### 固定一個系統的環境色

主題切在 `<html>` 上，和明暗一樣。要讓一個系統固定用某一組，在首繪前的腳本裡寫死：

```html
<script>
  document.documentElement.setAttribute("data-color-theme", "teal");
</script>
```

色票清單、語意與挑選的判準見[環境色票](/foundations/environment-palette)；
新增一組的步驟見[色票配色策略 → 新增一組主題](/foundations/choosing-a-palette#新增一組主題)。
