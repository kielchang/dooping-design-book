# 深淺主題

## 兩種宿主鉤子，同時支援

```css
.dark,
[data-theme="dark"] {
  --background: 222 22% 8%;
  /* … */
}
```

- `.dark` class —— Tailwind / shadcn 生態的慣例
- `[data-theme="dark"]` 屬性 —— Docusaurus、多數文件站與部分後台框架的慣例

## 切換要掛在 `documentElement`

```ts
document.documentElement.classList.toggle("dark", isDark);
document.documentElement.setAttribute("data-theme", isDark ? "dark" : "light");
```

## 深色是設計出來的，不是算出來的

深色 token **不是**淺色的反轉：不做機械式反轉亮度；沿用同色相、壓低飽和度、建立表面抬升階。

這套 token 的深色沿用淺色的冷靛藍色相，飽和度從 84% 壓到 16–22%，
並建立五級表面抬升。每個值都對深色實際背景重新驗對比，不沿用淺色的數字。

:::warning 對比要在真正的背景上驗
對實際頁面背景（`#101319`）驗，不對色票研究時常用的比較背景（例如 `#020817`）驗。
背景換了，對比結果就要重跑（做法見[色票配色策略](/foundations/choosing-a-palette#背景改版之後驗證結果全部作廢)）。
:::

## 圖表色票是兩組獨立的值，不是「有幾色不一樣」

淺深兩組分類色票**不得共用值**。

```ts
import { chartColors } from "@dooping/tokens";

chartColors("light"); // 8 色，L* 落在 30–62
chartColors("dark");  // 另外 8 色，L* 落在 49–86 —— 沒有任何一色與淺色相同
```

（守衛：`npm run verify:color`，淺深出現共用值就不合格；分類色票的規則見 [色彩語意](/foundations/color)）

## 多色相主題

深／淺是**明度**的兩種模式，色相主題是另一個維度。兩者正交，可以任意組合。

```html
<html data-theme="dark" data-color-theme="indigo">
```

- `data-theme` / `.dark` —— 明暗，既有機制不變
- `data-color-theme` —— 色相，**不設就是預設主題（石墨）**

### 主題影響哪些 token

每組主題每個模式共 22 個，分三類：

| 類別 | Token | 怎麼變 |
| --- | --- | --- |
| **主題色**（4） | `--brand`、`--brand-foreground`、`--brand-subtle`、`--brand-subtle-foreground` | 完整重新生成（對比反解） |
| **帶色調的中性色**（14） | `--background`、`--card`、`--popover`、`--muted`、`--secondary`、`--accent`、`--border`、`--input`、`--field-border`、`--field-editable`、`--field-readonly`、`--muted-foreground`、`--sidebar`、`--sidebar-border` | **只轉色相**，L 與 chroma 不動 |
| **側欄別名**（4） | `--sidebar-primary`、`--sidebar-primary-foreground`、`--sidebar-accent`、`--sidebar-accent-foreground` | ＝brand 家族的**字面值複製**（生成器保證同值，verify:color 的別名守衛盯住） |

**與主題無關的**：`--primary`（中性近黑，承擔多數控制項）、**`--ring`（聚焦環，
中性；要在六個主題最亮的表面上都過 3:1）**、
`--sidebar-ring`（≡ ring，同一條規則）、`--sidebar-foreground`（≡ foreground）、
全部狀態色、全部圖表色票、提醒視窗的 `--{狀態}-subtle`。

### 色相預算：主題色相只進識別層

| 介面層 | 吃主題色相？ | 載體 |
| --- | --- | --- |
| Layout 大區塊背景風格色調 | ✅（只轉色相） | 14 個帶色調中性色（含 `--sidebar`、`--sidebar-border`） |
| 選單／選中導覽項／品牌強調 | ✅ | `--brand` 家族（含 `Button` 的 `brand` variant——僅限一頁一顆的非提交型入口，這條沒有守衛，**人工：守門人，收新頁型或審 PR 時**；`--sidebar-primary`／`--sidebar-accent` 是它的別名） |
| 動作（確認／送出／儲存） | ❌ | `--primary` 中性近黑 |
| 互動（hover／pressed／已選） | ❌ | `currentColor` 疊加，機制無色相 |
| 聚焦環 | ❌ | `--ring` 中性，全主題一致 |
| 狀態／提醒色 | ❌ | 語意固定，見[提醒色辭典](/foundations/alert-colors) |
| 資料（圖表 8 色） | ❌ | 全主題共用 |

欄位提醒色（琥珀＝已改動、紅＝有問題）與聚焦環會出現在**同一個輸入框**上：
**彩色＝語意、中性＝焦點**，在所有主題下一致。

### 中性色帶主題色相

14 個帶色調中性色（chroma 0.007–0.023）跟著主題轉色相：

```
青玉  muted #f0f6f6   border #deeaea
苔綠  muted #f3f6f1   border #e4e9e1
紫晶  muted #f5f3f8   border #e9e5ee
```

**只轉色相、L 與 chroma 一律不動。**
唯一的例外是 `--muted-foreground`：對「該主題的 `--muted`」反解到 4.5:1 產生，
不是單純轉色相。

### 六組預設主題

| 名稱 | `data-color-theme` | OKLCH 色相 |
| --- | --- | --- |
| 石墨（預設） | `graphite` | 265°（**無品牌色**，`--brand` 鏡射 `--primary`） |
| 靛藍 | `indigo` | 272° |
| 藍紫 | `violet` | 292° |
| 紫晶 | `amethyst` | 305° |
| 青玉 | `teal` | 195° |
| 苔綠 | `moss` | 135° |

石墨沒有品牌色：`--brand` 鏡射 `--primary`，見
[色彩語意 → brand 的邊界](/foundations/color)。

### 新增主題：色相要避開狀態色

主題色相不得落在狀態色附近：

```
danger 17.7°  destructive 25.3°  warning 70.6°
edit 83.9°    success 162.4°     info 238.1°
```

主色要用約 245° 的藍，必須先移開 `info`（238°）。

新增主題的步驟（改 `THEMES`、生成、驗收）見
[色票配色策略 → 新增一組主題](/foundations/choosing-a-palette#新增一組主題)。
