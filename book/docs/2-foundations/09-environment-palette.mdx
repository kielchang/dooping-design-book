# 環境色票

主題（`data-color-theme`）只換**外殼**——側欄與頂列這個 L 形的大區塊——用顏色讓人一眼認出目前在哪個工作環境。
內容區一律中性：按鈕、提醒、欄位都在那裡，主題色碰不到它們。

這一頁給兩樣東西：**色票清單**，以及每個色族的**色彩學語意**。
哪個系統用哪一組，由整合方依自己的系統性質判斷；這裡只提供判斷的依據。
機制（怎麼設、主題島、外殼語境）見[深淺主題 → 環境色主題](/foundations/theming#環境色主題)。

- **色名**用華語的基本色名。落在基本色名中心的顏色叫得準、記得住，口頭溝通時說「青色那個」就夠。
- **色族**是同一個色名區。同族兩階看得出是一家；不同族一眼分得開。
- **色階**：`base` 是淺階，`deep` 是深階。兩階同色相、靠明度拉開。

（守衛：`npm run verify:color`。同族兩階 ΔE00 ≥ 8、跨族 ≥ 10、家族在色相上連續，
外殼上的文字與次要文字 ≥ 4.5:1，深色模式下外殼與內容底 ΔE00 ≥ 10。這張表與 tokens 的同步由
`tests/environment-theme.test.ts` 擋。）

## 色族的語意

色彩聯想會隨文化與情境改變；下面寫的是台灣使用者普遍的聯想，以及這套色票本身的感知性質。

| 色族 | 常見聯想 | 文化與情境 | 感知性質 |
| --- | --- | --- | --- |
| 灰（石墨、石板） | 中立、不帶立場 | 適合不屬於任何一類的環境，或跨環境的入口本身 | 最安靜；石板是唯一沒有色相的深色外殼 |
| 紅（莓紅） | 喜氣、隆重、熱絡 | 華人文化裡紅是吉祥色；台灣的行情顯示是**紅漲綠跌** | 全色票最「熱」的一族。這裡是深而低彩度的莓紅，和錯誤紅（`--danger`）差很遠 |
| 橙（赭） | 溫暖、親近、土地 | 赭石是傳統礦物顏料，帶泥土與手作感 | 暖色裡最柔和的一族 |
| 黃褐（橄欖） | 穩重、耐用、實在 | 橄欖綠、軍綠是常用色名，聯想到器材與實體物件 | 黃到綠之間，色覺異常時最容易和紅、綠混淆 |
| 綠（苔綠） | 成長、自然、通行 | 交通號誌的綠是「可以走」；但台灣的行情顯示綠色代表**跌** | 綠色環境裡的數字不要再上綠色，以免讀成下跌 |
| 青（青玉） | 冷靜、清透、專注 | 「青」是華語特有的色名，涵蓋藍綠之間；玉的聯想帶有沉穩 | 冷色裡最溫和的一族 |
| 青藍（湖水） | 清澈、開闊、技術感 | 介於青與藍之間 | 比藍更輕，比青更冷 |
| 藍（靛藍） | 信任、穩定、專業 | 企業軟體最常見的品牌色 | 長時間使用不易疲勞 |
| 紫（紫羅蘭、紫晶） | 創新、尊貴、想像 | 近年 AI 產品普遍採用藍紫到紫的色調 | 和藍族相鄰；色覺異常時藍↔紫會收斂 |

## 感知性質

- **全部是深色、低彩度。** 外殼的 OKLCH chroma 不超過 0.085，白字對比 ≥ 8.4:1。
  提醒淡底是淺色、狀態實色是中明度高彩度，三者在色彩空間裡離得很遠——所以外殼用紅、用綠都不會被讀成錯誤或成功。
- **深階比淺階安靜。** 正常畫面保持中性、顏色留給異常，警示才跳得出來（高效能 HMI 的原則）；
  需要讓異常最先被看到的環境，深階或中性的外殼干擾最小。
- **錯誤紅仍是畫面上最飽和的顏色。** 外殼的彩度遠低於 `--danger`，飽和度的階序不會反過來。
- **不靠顏色單獨辨識。** 紅綠色盲時紅↔綠↔黃褐、藍↔紫會收斂；外殼上一定要有系統名稱與標誌。

## 怎麼挑

這裡只給判準，用哪一組由整合方決定：

1. **先分類，再分色族。** 把會放在一起比較、使用者會在其間切換的系統分成幾類。
   同一類用同一族的深淺兩階（看得出是一家）；不同類跨族（一眼分得開）。
2. **讓語意和系統性質相合。** 依上一節的聯想挑色族；整組規則一致，比單一顏色「多像」更重要——
   使用者是拿整組顏色對整組系統來推論誰是誰。
3. **系統比色格多時共用。** 不常同時出現的系統可以共用一格，名稱與標誌照樣分得開。
4. **要新增色族或色格**，走[回饋與 RFC 流程](/governance/rfc)；新增的步驟與門檻見
   [色票配色策略 → 新增一組主題](/foundations/choosing-a-palette#新增一組主題)。

## 參考

- Jeffrey Heer、Maureen Stone，[Color Naming Models for Color Selection, Image Editing and Palette Design](https://idl.uw.edu/papers/color-naming-models)（CHI 2012）：色名的穩定度與色名距離。
- [Basic color categories and Mandarin Chinese color terms](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6261562/)（PLOS ONE 2018）：華語基本色名。
- Mukherjee 等，[Context Matters: A Theory of Semantic Discriminability for Perceptual Encoding Systems](https://arxiv.org/abs/2108.03685)：整組顏色對整組概念的推論。
- 高效能 HMI（ISA-101）：正常畫面中性、顏色留給異常。
- [Fluent 2 Color](https://fluent2.microsoft.design/color)：產品靠專屬品牌色區分，品牌色不鋪在大面積的內容上。
- 環境色的前例：Slack 的工作區側欄色、VS Code 的 Peacock 擴充（每個工作區染不同的外框色）、Chrome 設定檔的視窗框色。
