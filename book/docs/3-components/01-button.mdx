# Button 按鈕

觸發一個動作。

<StoryLink id="元件-基礎-按鈕・徽章・提示・卡片--按鈕" />

## 何時不要用

<Rules>
  <Do><p>導向另一個頁面 → 用連結（<code>&lt;a&gt;</code>）。需要長得像按鈕就用 <code>asChild</code>。</p></Do>
  <Dont><p>不要用 <code>&lt;button onClick=&#123;() =&gt; navigate()&#125;&gt;</code> 做導覽。</p></Dont>

## 變體

`default` 主要動作 · `secondary` 次要 · `outline` 外框 · `ghost` 淡化 · `link` 連結樣式 · `destructive` 破壞性動作

## 狀態

| 狀態 | 表現 |
| --- | --- |
| 預設 | 依變體 |
| hover | 狀態層 **6%**（疊一層 `currentColor`，不換底色） |
| **pressed** | 狀態層 **14%** |
| focus-visible | 2px 聚焦環 ＋ 2px 偏移（**只在鍵盤操作時出現**） |
| disabled | 透明度 50%、`pointer-events: none`，且**不套狀態層** |
| loading | **沒有獨立變體**：設 `disabled`、換旋轉圖示、改文案 |

hover 與 pressed 由 `.state-layer` 這個 utility 提供，六個變體共用同一組強度
（可見度 ΔE00 落在 **2.6–4.5**）。門檻見[互動狀態的顏色邏輯](/foundations/color#互動狀態的顏色邏輯)。

`link` 變體**不套**狀態層，hover 走底線。

loading 用既有的 disabled ＋ 圖示 ＋ 文案，不另做變體。
這是[載入中三種手段](/foundations/color#載入中中性三種手段各有位置)的第三種；
內容區域的載入用骨架或就地變暗，不要拿按鈕的做法去蓋整個畫面。

## 一顆畫面上只有一顆主要按鈕

`default` 變體只給「這個畫面最主要的那件事」，不要兩顆並排。

## 無障礙

- 圖示按鈕**必須**有 `aria-label`
- 破壞性動作建議搭配 [Dialog](/components/dialog) 二次確認
- 觸控裝置的按鈕至少 44px（`size="default"` 已達 40px，密集區域加 `tap-target`）
