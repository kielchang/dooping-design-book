# Badge 狀態徽章

標記一筆資料目前的狀態。

<StoryLink id="元件-基礎-按鈕・徽章・提示・卡片--徽章" />

## 何時不要用

<Rules>
  <Do><p>表示<strong>狀態</strong>（已完成、待審核、已退回）或<strong>數量</strong>（未讀 3）。</p></Do>
  <Dont><p>不要拿來當可點擊的篩選器；那應該是按鈕或 <a href="/components/chips">Chips</a>。</p></Dont>
</Rules>

<Demo title="語意變體">
  <div className="flex flex-wrap items-center gap-2">
    <Badge>預設</Badge>
    <Badge variant="secondary">次要</Badge>
    <Badge variant="outline">外框</Badge>
    <Badge variant="success">已完成</Badge>
    <Badge variant="warning">待補件</Badge>
    <Badge variant="info">審核中</Badge>
    <Badge variant="danger">已退回</Badge>
    <Badge variant="edit">已改動未送出</Badge>
  </div>
</Demo>

## 鐵律：徽章一定要有文字

不得只用純色點、純色塊表示狀態。

<Rules>
  <Do><p><code>&lt;Badge variant="danger"&gt;已退回&lt;/Badge&gt;</code></p></Do>
  <Dont><p><code>&lt;span className="size-2 rounded-full bg-danger" /&gt;</code></p></Dont>
</Rules>

## 預設是淡底，實色只給例外

四種狀態變體走**淡底層**（`--{狀態}-subtle` ＋ `--{狀態}-subtle-foreground`），
與[提示框的低強度](/components/callout)同一組 token。需要喊的場合才傳
`intensity="high"` 換成實色滿版。

**資料表裡一律用預設。**

`edit` 是唯一帶**可見邊框**的變體，標記「已改動未送出」
（琥珀保留色，見[提醒色辭典](/foundations/alert-colors)），必須與一般狀態分得開。

狀態變體的預設樣式不得出現實色填底。（守衛：`npm test`）

## 狀態對應建議

| 語意 | variant | 例 |
| --- | --- | --- |
| 完成／通過 | `success` | 已完成、已核准 |
| 進行中／中性 | `info` | 審核中、處理中 |
| 需注意但不阻擋 | `warning` | 待補件、即將到期 |
| 異常／失敗 | `danger` | 已退回、已取消 |
| 草稿／非活躍 | `secondary` | 草稿、已封存 |

## 徽章的文字要短到能被掃視

<Rules>
  <Do><p>控制在 <strong>2–6 個字</strong>：「已完成」「待補件」「審核中」。
  需要解釋原因時，把原因放進 <a href="/components/tooltip">Tooltip</a>，徽章本身維持短。</p></Do>
  <Dont><p>不要放整句話：「此筆因附件資訊不完整而暫停處理」。</p></Dont>
</Rules>

### 需要更多字時，換元件

| 你想說的 | 該用 |
| --- | --- |
| 這筆是什麼狀態（2–6 字） | Badge |
| 為什麼是這個狀態（一句話） | Badge ＋ [Tooltip](/components/tooltip) |
| 這一整區有問題，且要一直看得到 | [Callout](/components/callout) |

徽章不換行、也不截斷成 `…`。**寫不短就換元件**。
