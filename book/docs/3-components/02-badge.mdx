# Badge 狀態徽章

標記一筆資料目前的狀態。

## 何時不要用

<Rules>
  <Do><p>表示<strong>狀態</strong>（已出貨、待審核、已退回）或<strong>數量</strong>（未讀 3）。</p></Do>
  <Dont><p>不要拿來當可點擊的篩選器。看起來像標籤、按下去卻有動作，
  使用者要試過才知道——那應該是按鈕或 <a href="/components/chips">Chips</a>。</p></Dont>
</Rules>

## 鐵律：徽章一定要有文字

純色點、純色塊在以下情況等於消失：

- 灰階列印（後台系統的報表**一定**會被印出來簽核）
- 紅綠色覺障礙（約 8% 男性）
- 深色模式下的低飽和色

<Rules>
  <Do><p><code>&lt;Badge variant="danger"&gt;已退回&lt;/Badge&gt;</code></p></Do>
  <Dont><p><code>&lt;span className="size-2 rounded-full bg-danger" /&gt;</code>
  ——這個紅點在印出來的報表上是一個灰點，在色覺障礙者眼裡是一個灰點。</p></Dont>
</Rules>

## 狀態對應建議

| 語意 | variant | 例 |
| --- | --- | --- |
| 完成／通過 | `success` | 已出貨、已核准 |
| 進行中／中性 | `info` | 審核中、處理中 |
| 需注意但不阻擋 | `warning` | 待補件、即將到期 |
| 異常／失敗 | `danger` | 已退回、已取消 |
| 草稿／非活躍 | `secondary` | 草稿、已封存 |
