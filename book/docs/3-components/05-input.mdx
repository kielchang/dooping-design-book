## 何時不要用

<Rules>

## 高度是 36px，而且不要改

Input、Select、EditableField 全部 36px（`--size-control`）。

## placeholder 不是 label

<Rules>
  <Do><p>永遠有 <code>&lt;Label&gt;</code>。placeholder 放<strong>格式範例</strong>（「例：U-1042」）。</p></Do>
  <Dont><p>不要用 placeholder 當 label。</p></Dont>
</Rules>

## 錯誤態：FormField 把固定寫法接好

欄位錯誤是**欄位層**的語意事件：`aria-invalid` 讓邊框轉 `--danger`，
錯誤小字＋圖示就地顯示在欄位下（色＋圖示＋文字三重編碼）。
聚焦環照常是中性的：**語意用彩色、焦點用中性**
（[提醒色辭典](/foundations/alert-colors)的分工）。
錯誤欄**不整格染紅**（不加淡底）；主訊號是邊框與錯誤小字。（守衛：`npm run verify:color`）

`FormField` 把「Label＋`aria-describedby`＋`aria-invalid`＋錯誤小字」的固定寫法元件化，
id 連動自動接好，取用端不手寫這三條 aria：

<Demo title="錯誤欄聚焦看看：danger 邊框（語意）與中性聚焦環（焦點）同框">
  <div className="max-w-sm space-y-4">
    <FormField label="名稱" hint="2–20 個字" required>
      <Input placeholder="輸入名稱" />
    </FormField>
    <FormField label="數量" required error="必須大於 0">
      <Input defaultValue="0" inputMode="numeric" />
    </FormField>
  </div>
</Demo>

多欄錯誤的**彙總**由區塊層的 [Callout](/components/callout)（`live`）負責：
它報「有幾個欄位要修」，不重複每一條內容。

### 可聚焦的不是根元件時：children 傳函式

`FormField` 預設把 `id`／`aria-*` 注入唯一的子元素。可聚焦的不是根元件時
（例：Radix 的 Select 能聚焦的是 `SelectTrigger`，不是 `Select` 根元件），
`children` 改傳函式，把收到的屬性展開到真正可聚焦的那個元素上：

```tsx
<FormField label="所屬單位" required error={unitError}>
  {(control) => (
    <Select value={unit} onValueChange={setUnit}>
      <SelectTrigger {...control}><SelectValue /></SelectTrigger>
      <SelectContent>…</SelectContent>
    </Select>
  )}
</FormField>
```

不要為了下拉退回手寫 `Label htmlFor`＋`id`。
