# NumberInput 數值輸入

輸入數字。

<StoryLink id="元件-表單-輸入控制項--文字與數值" />

## 三件小事

三件缺一不可：

1. **`inputMode="numeric"`**：手機直接跳數字鍵盤
2. **`tabular-nums`**：等寬數字
3. **右對齊**

底色套 `.field-editable`，與其他可編輯欄位長相一致。

<Demo title="數值輸入">
  <div className="space-y-2">
    <Label>訂購數量</Label>
    <NumberInput value={120} onChange={() => {}} min={0} step={10} aria-label="訂購數量" />
  </div>
</Demo>

## 何時不要用

<Rules>
  <Do><p>數量、金額、比率這類**會被拿去計算**的值。</p></Do>
  <Dont><p>不要用在「看起來是數字但其實是代碼」的欄位（編號、統一編號、電話）；那些是字串。</p></Dont>
</Rules>

## 滾輪改值

在長表單裡建議由宿主加 `onWheel={(e) => e.currentTarget.blur()}`。

npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/number-input.json
