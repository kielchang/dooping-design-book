# DataTable 資料表

**後台系統的主力元件。** 一份欄位設定，換來搜尋、篩選、排序、分頁、合計、凍結首欄與匯出。

## 外觀不變量：只有列底線

與 <a href="/components/table">Table</a> 相同：表格本體**沒有外框、沒有直向格線、
儲存格沒有邊框**，唯一的線是列與列之間 `--border` 的 1px 底線。
篩選面板是 `popover` 底、`--border` 1px 框，portal 到 `body` 直下；
宿主的樣式基座必須涵蓋 portal 內容，不能只鋪在範例容器裡。（守衛：`npm run verify:book`）

## 欄位設定就是全部的 API

```tsx
const columns: Column<Order>[] = [
  {
    key: "amount",
    header: "金額",
    numeric: true,                          // 右對齊 ＋ 等寬數字
    cell: (r) => formatMoney(r.amount),     // 顯示
    sortValue: (r) => r.amount,             // 有這個才可排序
    filterText: (r) => String(r.amount),    // 參與關鍵字搜尋
    filter: "range",                        // 單欄篩選型態（可自動判定）
    total: (rows) => formatMoney(sum(rows)),// 合計
    freeze: true,                           // 凍結首欄
    truncate: 180,                          // 超寬截斷 ＋ 提示泡泡
    width: 140,                             // 初始欄寬（使用者仍可拖曳調整）
    headerClassName: "text-right",          // 只作用在表頭那一格
  },
];
```

## 分頁、合計、匯出

- **門檻式分頁**：資料筆數沒超過一頁就**不顯示分頁器**。
- **合計算「篩選後全部」**，不是當頁。
- **匯出跟著畫面**：匯出的是使用者**現在看到的**（篩選＋排序後），不是原始全量。

## 每頁筆數：5／15／30／50

| 檔位 | 用在什麼時候 |
| --- | --- |
| 5 | 嵌在卡片或對話框裡的小表——表格不是這個畫面的主角 |
| **15**（預設） | 一般筆電螢幕一頁看得完，不必捲。**日常作業的預設** |
| 30 | 要在兩批之間來回比對 |
| 50 | 掃視模式：用眼睛掃過一整片找異常，不是找特定一筆 |

  <Dont><p>不要加「全部」。要全部就匯出 CSV。</p></Dont>

## 單欄篩選的三種型態

| 型態 | 互動 | 自動判定條件 |
| --- | --- | --- |
| `text` | 可加多筆關鍵字，**符合任一即列出**（同欄 OR、跨欄 AND） | 有 `filterText`／`sortValue` |
| `range` | 最小～最大 | 數字欄且可排序 |
| `select` | 從該欄不重複值多選 | 需明確指定 |

文字篩選面板依輸入推薦最相似的 3 個既有值。

## 篩選條件可以逐條移除

每個條件都是獨立標籤，能個別拿掉；不要只提供「一次全清」。

## 載入：兩種長相，元件自己分

`loading` 一個 prop，長相由「有沒有資料」決定（規範見〈[載入中](/foundations/color#載入中中性三種手段各有位置)〉）：

| 情境 | 長相 |
| --- | --- |
| `loading` 且還沒有資料（首載） | **骨架列**：表頭是真的、列是灰塊，列數＝每頁筆數（上限 15），版面不跳動 |
| `loading` 且已有資料（重查、換篩選） | **就地變暗＋資料列脈動**（表頭不動）＋鎖互動＋`aria-busy`；舊資料仍可讀，**不蓋骨架** |

讀屏出口由容器宣告一次（`role="status"` 的「載入中…」，文案走 `labels` 覆寫），
骨架塊本身 `aria-hidden`。

## 空狀態分兩種

| 情境 | 文案 |
| --- | --- |
| 沒有資料 | 用 `empty` prop 自訂，通常帶「建立第一筆」的行動 |
| 篩選後沒有結果 | 元件自動切換成「查無符合的資料／請調整關鍵字或欄位篩選」 |

## 十字對準

滑鼠指到哪一格，就 highlight 整行整列。

- highlight 用**背景漸層圖層**，不用 `background-color`。
- **`cn()` 要把 `bg-gradient-to-*` 認成背景圖片**（`utils` 已登記）。自己換掉 `cn` 的宿主要保留這條。
- **勾選欄固定 2.5rem**（`w-10 min-w-10`）；有勾選欄時，凍結首欄 sticky 在 `left: 2.5rem`。

（守衛：宿主渲染守衛 `npm run verify:host` 在 390px 寬檢查）

## 欄寬可調與雙擊自適應

拖曳欄位右邊界可調寬，**雙擊該邊界則自動貼合內容**。

  <Do><p>調整後的欄寬只活在<strong>當次瀏覽</strong>。</p></Do>
  <Dont><p>不要把欄寬存進使用者設定，除非有明確的「儲存這個版面」動作。</p></Dont>

## 版面開關：預設就是規範

| Prop | 預設 | 什麼時候才該改 |
| --- | --- | --- |
| `zebra` | `true` | 表格只有 2–3 列時可關 |
| `dense` | `false` | 一次要看很多列的**掃視型**表格。手機上不要用 |
| `stickyHeader` | `true` | 幾乎不該關。列印時元件已自動改用 `table-header-group`（見 [Table](/components/table)） |
| `crosshair` | `true` | 欄位少於 4 欄時關掉 |
| `resizable` | `true` | 欄寬經過精算的固定版面（例如要對齊上方的統計卡）可關 |

<Rules>
  <Do><p>同一個系統裡，同一類表格用同一組開關。</p></Do>
  <Dont><p>不要每張表各自調。</p></Dont>
</Rules>

## 多選與批次操作

<StoryLink id="元件-資料-資料表-datatable--批次操作" />

`selectable` 在首欄前插勾選欄；`bulkActions` 給批次操作列（有選取才出現，
sticky 在容器內置底，`role="toolbar"`＋方向鍵移動焦點）。三條規則：

- **表頭勾選只切當頁。**
- **選取跨頁保留**（鍵＝`getRowKey`，所以 `getRowKey` 不得依賴 index）。
- 選取是**暫時狀態**：不進網址（見下）、換資料集自行清除。

```tsx
<DataTable selectable bulkActions={({ selected, clear }) => (
  <Button size="sm" onClick={() => { doExport(selected); clear(); }}>匯出所選</Button>
)} … />
```

## Facet 篩選鈕與欄位顯示

<StoryLink id="元件-資料-資料表-datatable--facet-篩選" />

`facets={["status"]}` 把 select 型欄位升級成工具列上的 faceted 鈕（Popover＋逐值計數）。
它與表頭篩選**共用同一份狀態**，從哪邊改都反映在同一排篩選 chip。
逐值計數對「排除本欄的其餘篩選後」的列集合計算。

`columnVisibility` 顯示「欄位」切換鈕；欄位設定加 `hideable`（凍結欄強制不可隱藏）
與 `defaultHidden`。欄位顯示是暫時狀態，不進網址。

## 狀態同步網址

<StoryLink id="元件-資料-資料表-datatable--網址同步" />

[後台系統的資訊架構](/patterns/back-office-ia)的深連結規範在資料表上的做法：

```tsx
const { state, onStateChange } = useTableUrlState();
<DataTable state={state} onStateChange={onStateChange} … />
```

- 網址參數人看得懂：`q=甲`、`sort=amount.desc`、`page=2`（1-based）、
  `f.status=已確認`、`fr.amount=1000..5000`；**預設值一律省略**。
- 篩選／搜尋變更自動回第 1 頁（`page` 參數消失）。
- `selection` 與 `hiddenColumns` 不進網址——判準是「別人打開這個連結，
  需要看到一樣的東西嗎？」。
- 預設走 `history.replaceState`；TanStack Router／Next 宿主注入自己的
  `adapter`（get／set／subscribe 三個函式）。同頁多張表用 `prefix` 隔開。

`state`／`onStateChange` 是**逐鍵受控**：給了哪個鍵、哪個鍵由宿主管理，其餘維持元件內部狀態。

## 資料量上限

門檻式分頁讓「一頁最多 50 列」成為渲染上限，但**篩選與排序仍然掃全量**。

| 資料量 | 做法 |
| --- | --- |
| ≤ 500 筆 | 全部即時，包含關鍵字搜尋 |
| 500 – 5,000 筆 | 仍可用；輸入搜尋時每個字元都重算 |
| ＞ 5,000 筆 | **改由伺服器端分頁與篩選**，元件只負責呈現當頁 |

超寬表格（10 欄以上）：

  <Dont><p>不要靠水平捲動塞 20 欄。次要欄位收進展開列或明細頁。</p></Dont>

## 無障礙

- 排序表頭帶 `aria-sort`
- 篩選鈕帶 `aria-label`（「篩選 單位」）
- 整列可點（`onRowClick`）：鍵盤與讀屏的入口是首個可見欄的真 `<button>`（Enter／Space 觸發、名字就是首欄內容）；
  列本身只接滑鼠點擊、**不是** button。首欄的 `cell` 不要再渲染連結或按鈕：它已經是入口
- 篩選面板走 portal ＋ fixed 定位
