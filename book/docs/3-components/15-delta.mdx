# Delta 變異顯示

顯示「和基準比差了多少」。

<StoryLink id="元件-狀態-變異・空狀態・分頁・步驟--變異顯示" />

## 三重編碼

**箭頭 ▲▼ ＋ 文字 ＋ 顏色。** 箭頭與文字必須**自己就能把話說完**，
灰階列印與紅綠色覺障礙下仍讀得懂；顏色只是加速。

<Demo title="變異顯示">
  <div className="space-y-2 text-sm">
    <p>本月營收與上月比較：<Delta value={128400} posLabel="增加 " negLabel="減少 " /></p>
    <p>誤差數（越少越好）：<Delta value={340} goodWhen="negative" posLabel="超出 " negLabel="短少 " /></p>
    <p>交期落差：<Delta value={-3} goodWhen="negative" posLabel="延遲 " negLabel="提前 " format={(n) => `${n} 天`} /></p>
    <p>與上期持平：<Delta value={0} /></p>
  </div>
</Demo>

## `goodWhen`：好壞是業務決定，不是數學決定

元件不猜方向：由呼叫端用 `goodWhen` 明確指定哪個方向算好。

<Rules>
  <Do><p>每次用 Delta 都想一次：這個數字變大，對使用者是好消息還是壞消息？</p></Do>
  <Dont><p>不要預設「正值＝綠色」。</p></Dont>
</Rules>

## 零值也要說話

`value === 0` 顯示「— 持平」，而不是空白或 `0`。
