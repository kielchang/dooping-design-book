# EmptyState 空狀態

沒有資料時，畫面該說什麼。

## 三種空是不一樣的

這是最常被偷懶的地方：全部塞同一句「查無資料」。但使用者面對的其實是三種完全不同的處境。

| 情境 | 使用者的問題 | 文案該回答 |
| --- | --- | --- |
| 還沒有資料 | 我該做什麼？ | 引導建立第一筆 |
| 篩選後沒結果 | 我是不是篩錯了？ | 說出目前條件，引導放寬 |
| 沒有權限 | 是壞掉了嗎？ | 說明原因與找誰 |

<Rules>
  <Do><p>空狀態要有<strong>下一步</strong>。使用者到這裡是卡住了，不是來看插圖的。</p></Do>
  <Dont><p>不要只寫「無資料」。這句話沒有回答任何一種處境。</p></Dont>
</Rules>

## 不要放大型插畫

後台系統的空狀態一天可能出現幾十次（每次篩選都會遇到）。
大型插畫第一次可愛，第五次就開始佔位子。圖示 ＋ 兩行字即可。
