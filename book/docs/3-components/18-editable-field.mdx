## 支援的欄位型態

| `kind` | 編輯態 |
| --- | --- |
| `text` / `date` | 輸入框 |
| `number` / `money` / `rate` | 右對齊數字輸入 |
| `select` | 下拉（點擊即自動展開） |
| `radio` / `checkbox` | [SegGroup](/components/seg-group) 分段選擇 |
| `multiselect` | [Chips](/components/chips) 標籤片 |

`rate` 欄位對使用者顯示「%」，存的是比值：輸入時 ×100、送出時 ÷100，不要讓使用者自己換算。

## 數值的三條顯示規則

`number` / `money` / `rate` 三種型態在**唯讀態**的呈現有三條規則。

### 1. 千分位、等寬數字、右對齊

三者必須同時套用。

### 2. 顯示不四捨五入

<Rules>
  <Do><p>存的是多少就顯示多少。<code>168.5</code> 顯示 <code>168.5</code>。</p></Do>
  <Dont><p>不要為了版面整齊而在顯示時四捨五入。</p></Dont>
</Rules>

真的需要進位，**在資料層做**，而且要讓使用者知道進位規則。

### 3. 負值用會計括號 ＋ 紅字

`money` 型態的負值顯示成 `($2,000)` 而不是 `-$2,000`。
括號是主要線索，紅字是第二條線索，灰階列印下括號仍要有效——[顏色永遠不是唯一線索](/foundations/color)。

`number` 型態不套會計括號。

## `unit` 是顯示層的事，不進值裡

```tsx
<EditableField label="總重量" kind="number" value={168.5} unit="kg" … />
```

唯讀態顯示 `168.5 kg`，編輯態只有 `168.5`。

<Rules>
  <Do><p>單位用 <code>unit</code> prop。值本身永遠是純數字。</p></Do>
  <Dont><p>不要把單位塞進值裡（<code>"168.5 kg"</code>）。</p></Dont>
</Rules>

## 已改動未送出＝琥珀

值 ≠ 原值時整欄標琥珀（邊框＋底色＋文字＋「已變更」標籤）。
這個顏色是[保留色](/foundations/color)，不做別的用途。

## undo / redo 都會先確認

顯示「舊值 → 新值」，確認才執行。

<Rules>
  <Do><p>還原前先問一次。<strong>「還原」本身也是一次資料變更</strong>。</p></Do>
  <Dont><p>不要做一鍵無聲還原。</p></Dont>
</Rules>

## 可發現性：低調的鉛筆

唯讀態右側有一個很淡的鉛筆圖示，hover 加深；觸控裝置上恆微顯。

## 鎖定態

`disabled` ＋ `lockHint`。三個細節：

- 顯示鎖頭圖示（不只是變灰）
- **仍然可以聚焦**；鎖定原因要讀屏唸得到
- `aria-label` 帶上鎖定原因

搭配[硬鎖定模式](/patterns/hard-lock)使用。

## 極端值

設定表單的欄寬固定（響應式 grid 的一格，約 288px）。塞進極端值時的行為如下，**這些是規格**：

| 極端情況 | 行為 |
| --- | --- |
| 超長文字值 | 唯讀態截斷 ＋ Tooltip 顯示完整；編輯態正常水平捲動。**不換行** |
| 超長欄位標籤 | 標籤換行（可以佔兩行），欄位本身不變形 |
| 13 位數金額 | 千分位照樣分組，容器水平捲動。**不縮小字級** |
| 多選 24 個選項 | 標籤片區塊自動換行成多列，欄位變高 |
| 單選 6 個長標籤 | 分段列換行。此時應該改用 `select`，不要讓 [SegGroup](/components/seg-group) 換行 |

<Rules>
  <Do><p>把最長的真實資料放進最窄的欄位裡試一次。</p></Do>
  <Dont><p>不要只用示範資料驗收。</p></Dont>
</Rules>

## 新增模式

```tsx
<EditableField alwaysEdit trackChanges={false} … />
```

恆為輸入態，且不會把整張表單標成「已變更」。
