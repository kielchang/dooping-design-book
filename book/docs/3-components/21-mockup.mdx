## 初始畫面不能取決於瀏覽器環境

文件站是靜態產生的：初始值固定，掛載後才套用瀏覽器環境。

```tsx
// ✗ 伺服器端沒有 matchMedia；就算加了防呆，
//   伺服器算出 false、瀏覽器算出 true → hydration mismatch
const [expanded, setExpanded] = useState(
  window.matchMedia("(prefers-reduced-motion: reduce)").matches
);

// ✓ 初始值固定，掛載後才套用使用者偏好
const [expanded, setExpanded] = useState(false);
useEffect(() => {
  if (window.matchMedia?.("(prefers-reduced-motion: reduce)").matches) setExpanded(true);
}, []);
```

這條適用於**所有**取決於瀏覽器環境的初始狀態：主題偏好、視窗寬度、觸控能力、
減少動態偏好。hydration 不一致只在正式建置後看得到，`npm start` 的開發模式不會重現。

## 聚光用的是同一套視覺語言

`<Spotlight>` 用的 `.spotlight-ring` 與 [Coachmark](/components/coachmark) 完全相同。

琥珀色專屬「已改動未送出」，不得用於聚光。

## 播放器的元件層規約

把多張示意圖串成一條流程的**多步播放器**（模式層的說明見
[零截圖文件示意](/patterns/zero-screenshot-docs#多步流程播放器)）不在本元件庫裡；
自行實作時照以下規約。

上面的〈初始畫面不能取決於瀏覽器環境〉同樣適用。

### 減少動態偏好：預設展開，不輪播

開啟「減少動態」的使用者，看到的應該是**全部展開的靜態版本**，
而不是「一樣會輪播，只是沒有轉場動畫」。

### 控制項要夠大

| 控制項 | 規格 |
| --- | --- |
| 上一步／下一步 | **文字按鈕**（「‹ 上一步」），桌機 36px 高 |
| 步驟圓點 | 視覺 10px，**命中區 28px** |
| 全部控制項 | 觸控裝置由 `tap-target` 撐到 **44px**（見[無障礙四原則](/accessibility/principles)） |

字幕要**獨立一行**放在按鈕上方，不要和按鈕擠在同一列。

### 小螢幕：讓示意圖自己捲

示意圖有最小寬度。窄螢幕**讓步驟容器橫向捲動**，不要讓示意圖跟著縮。

```css
.flow-step { overflow-x: auto; }
.mock-frame { min-width: 460px; }
```

<Rules>
  <Do><p>讓<strong>示意圖自己捲</strong>，頁面不捲。</p></Do>
  <Dont><p>不要讓整個頁面出現橫向捲軸。</p></Dont>
</Rules>

### 字幕格式

| 位置 | 格式 |
| --- | --- |
| 每一步 | `①` `②` `③` 開頭 ＋ **一句**「做什麼」 |
| 最後一步 | 盡量寫「**完成後你會看到：…**」 |
| 單張示意圖 | 標題＝一句話主旨；字幕＝一句補充（位置或後果） |

「完成後你會看到」要寫成讀者能自己核對的**驗收條件**。

<Rules>
  <Do><p>一張示意圖<strong>最多一個聚光</strong>。次要資訊用徽章或提示框呈現。</p></Do>
  <Dont><p>不要一張圖圈三個地方。</p></Dont>
</Rules>
