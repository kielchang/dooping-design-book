# 工具函式與 hook

這六項是元件的**相依**——你 `npx shadcn add` 任何一個元件時，需要的會被自動裝進
`lib/dooping/`。它們單獨也能用。

```
src/lib/dooping/
├── utils.ts        cn ＋ 數值格式化
├── use-sort.ts     三態排序
├── csv.ts          CSV 序列化與解析
├── download.ts     觸發瀏覽器下載
└── forms-diff.ts   FieldSpec 驅動的變更偵測
src/components/dooping/
└── use-record-diff.ts   草稿 vs 原始值
```

## `utils` — `cn` 與數值格式化

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/utils.json
```

**`cn(...inputs)`**：`clsx` ＋ `tailwind-merge`，後面的 class 覆蓋前面的。所有元件都依賴它。

```ts
cn("px-2 py-1", isActive && "bg-primary", className)
```

其餘五個是**數值顯示**的格式化：

| 函式 | 用途 |
| --- | --- |
| `formatNumber(n, locale?)` | 千分位整數 |
| `formatMoney(n, { symbol?, locale? })` | 金額，預設 `$` |
| `formatPercent(value, digits = 1)` | 百分比 |
| `formatRatio(value, digits = 0)` | 比率 |
| `formatSigned(n, format?)` | 帶正負號，可換底層格式化器 |

`formatSigned` 的第二參數用來組合：`formatSigned(delta, formatMoney)`
就是「帶正負號的金額」。[Delta 變異顯示](/components/delta)內部用的就是這個。

## `use-sort` — 三態排序

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/use-sort.json
```

```ts
const { sorted, sortState, toggleSort } = useSort(rows, initialState);
```

排序狀態是 **無 → 大到小 → 小到大 → 無** 的三態循環，不是兩態。

`SortState` 是 `{ key, dir } | null`，`null` 就是那個「無」（原始順序）。

## `csv` — 序列化與解析

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/csv.json
```

| 函式 | 說明 |
| --- | --- |
| `csvSerialize(headers, rows, bom = true)` | 產出 CSV 字串 |
| `csvEscape(v)` | 單一值的跳脫（逗號、引號、換行） |
| `csvParse(text)` | 解析回二維陣列 |

**`bom` 預設是 `true`，不要關掉。**

## `forms-diff` — FieldSpec 驅動的變更偵測

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/forms-diff.json
```

這是[逐欄編輯](/patterns/inline-field-editing)與[變更摘要](/components/change-summary)的底層。

核心是 **`FieldSpec`**：用資料描述每個欄位「叫什麼、是什麼型別、怎麼顯示」，
比對與顯示都由它推導。

| 匯出 | 用途 |
| --- | --- |
| `FieldSpec` / `FieldKind` / `Change` | 型別 |
| `eqValue(a, b)` | 值比對——**空字串、`null`、`undefined` 視為相同** |
| `isEmptyValue(v)` | 空值判定 |
| `fmtValue(v, kind, format?, unit?)` | 依欄位型別格式化顯示值 |

依 `eqValue`，表單裡「清空一個本來就是 `null` 的欄位」不算一次變更。

## `use-record-diff` — 草稿 vs 原始值

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/use-record-diff.json
```

```ts
const { draft, changes, setField, revertField, revertAll } = useRecordDiff(original, specs);
```

把「原始值」與「草稿」分開保存，隨時算得出兩者的差異。
[ChangeSummary](/components/change-summary) 吃的就是它的 `changes`。

`revertField(key)` 把草稿的那一格寫回原始值。
