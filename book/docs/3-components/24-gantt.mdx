# Gantt 時間軸

**檢視與選取用的精簡時間軸**：左欄項目、右欄長條，加上刻度、格線與今天線。
用來呈現「哪些項目在什麼期間、進行到哪」，不做拖拉排程。

<StoryLink id="元件-特殊介面-時間軸・節點畫布--時間軸-互動">互動 playground——可調項目數與時間跨度</StoryLink>

## 何時不要用

- **要拖拉改期、要相依線（前置後續）、要週期規則**：那是排程編輯器，不用這支。
- **超過一兩百列**：這支逐列渲染，沒有虛擬捲動。列多先分組或分頁。
- **只是要顯示一個日期區間**：用文字。

## 改期怎麼做

選中一列之後，用旁邊的表單改日期，與[逐欄編輯](/patterns/inline-field-editing)同一個模式：
改動標琥珀、送出前看[變更摘要](/components/change-summary)。

## 色彩：每一層吃什麼

| 元素 | 吃什麼 | 規則 |
| --- | --- | --- |
| 長條 | `--chart-N`（`category` 1–8） | 顏色編**類別**不編狀態：甲案在時間軸、圖表、畫布上永遠同色（[配色策略](/components/charts#配色策略先問資料形態再問維度語意)） |
| 進度 | 未完成段蓋 `--background/45%` | 實色＝已完成、淡段＝剩餘；不換色相 |
| 今天線 | `--foreground/50%`（中性） | 結構標記不吃狀態色 |
| 列互動 | `state-layer` 6%／14%／20% | 與[資料表列](/patterns/data-table-standard#三種列狀態要真的分得開)同一套 |

## 狀態

| 狀態 | 表現 |
| --- | --- |
| hover | 狀態層 6%（整列，含左欄與時間軸） |
| pressed | 狀態層 14% |
| 已選 | 狀態層 20%；**次要文字換回正文色** |
| focus-visible | 2px 聚焦環＋2px 偏移（列是 `<button>`，只在有 `onSelect` 時） |
| 空 | `items` 為空時顯示內建[空狀態](/components/empty-state)，不畫空刻度；文案與行動用 `empty` 客製（與資料表同形），省略時用 `labels.emptyTitle` |

## 刻度與粒度

跨度 ≤21 天出**日**刻度、≤120 天出**週一**刻度、更長出**月初**刻度。不做縮放切換。

視窗省略時由資料推導，前後各留 5% 邊距。今天線只在落於視窗內時出現。
`items` 為空時不畫刻度，直接顯示內建空狀態。

## 無障礙

- 有 `onSelect` 時每列是真的 `<button>`：Tab 可及、`aria-pressed` 表達選取。
- 每列的 `aria-label` 含完整資訊：`名稱，起 到 迄，進度 n%`。
- 顏色永遠不是唯一線索：分類靠左欄文字、進度有數字可讀、狀態靠徽章文字。
