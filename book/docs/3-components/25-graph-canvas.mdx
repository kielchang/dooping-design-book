# GraphCanvas 節點畫布

**流程圖與關聯圖的畫布**：節點、連線、拖拉、縮放、minimap。
底層是 [React Flow](https://reactflow.dev)（`@xyflow/react`，MIT）；
取用端依賴的是 `<GraphCanvas>` 的領域 API，不是 React Flow 本身。

## 薄封裝：相依關在一個檔案裡

**相依關在一個檔案裡**：只有 `graph-canvas.tsx` 能 import `@xyflow/react`（[元件庫邊界](/governance/drift-guards)）。
取用端與其他元件依賴 `<GraphCanvas>` 的節點／連線型別。（守衛：`tests/boundary.test.ts` 的隔離守衛）

封裝已處理三件事，取用端不必再做：樣式表 import、wrapper 高度、`nodeTypes` 定義在模組層。

## 色彩：token 橋接層

React Flow 自帶一整套 `--xy-*` 視覺變數。封裝把它們對映到本書的語意 token，
依[主題](/foundations/theming)的色相預算逐層對位（畫布在內容區，主題色不進來）：

| 畫布元素 | 介面層 | 吃什麼 | 隨主題變 |
| --- | --- | --- | --- |
| 畫布底、格點 | Layout | `--background`／`--border` | ❌ 中性 |
| 節點框、控制列、minimap | 表面 | `--card` 家族 | ❌ 中性 |
| 連線、handle | 結構 | `--muted-foreground`／`--border` | ❌ 中性 |
| hover／已選 | 互動 | `state-layer` 6%／20% | ❌ 中性 |
| 鍵盤聚焦 | 聚焦 | `--ring` 外環 | ❌ 中性 |
| 節點分類色條 | 資料 | `--chart-N` | 與主題無關，跟資料實體走 |

全部落在既有 token 上，**深淺模式自動成立，切環境色主題畫布不變**。
不要另用 React Flow 自己的 `colorMode`。

### 已選與聚焦是兩個通道

- **已選** ＝ 節點背景疊狀態層 20%（與資料表列同一套機制）
- **鍵盤聚焦** ＝ `--ring` 外環（offset 畫法：先一圈背景色、再一圈環）

兩者可以同時存在：「不合格＋聚焦」「已選＋聚焦」都成立。

## 何時不要用

- **資料超過幾百個節點**：逐節點 DOM 渲染，上千節點先在資料層彙總。
- **只是要畫一張靜態流程示意**：文件裡用[零截圖示意](/patterns/zero-screenshot-docs)
  或一張 SVG。
- **要當白板**（自由文字、便利貼、手繪）。

## 唯讀模式

`readOnly` 拿掉拖拉與連線，保留選取與縮放。文件內嵌示意、稽核檢視用這個。

## 無障礙

- 外層 `role="img"` ＋ `aria-label`。**關鍵資訊不能只存在於畫布裡**：旁邊要有等價的清單或表格
  （與[圖表的無障礙義務](/components/charts#無障礙顏色不能是唯一線索)同一條規則）。
- 節點分類靠色條＋（宿主提供的）文字，不是只有顏色。

## 取用

```bash
npx shadcn add https://kielchang.github.io/dooping-design-book/r/graph-canvas.json
```

registry item 會一併安裝 `@xyflow/react`。
需要 tokens ≥ 0.6.0。抄走之後**不要**在其他檔案 import `@xyflow/react`；
隔離守衛建議一起抄走（見[漂移防護](/governance/drift-guards)）。
