# DateRange 期間選擇

儀表板與清單篩選的時間範圍。**檔位是一等公民**：今日／近 7 日／近 30 日／本月
一鍵切換，「自訂」才展開起訖輸入。

## 行為規範

| 規則 | 說明 |
| --- | --- |
| 檔位含今日 | 「近 7 日」＝含今日往回 7 天；「本月」＝本月 1 日至今日 |
| 起訖反了自動修正 | 把「起」選到「迄」之後，另一端夾到同一天；不跳錯誤訊息 |
| 值的格式 | `yyyy-mm-dd`（本地日期，不含時區）；跨時區解讀由宿主決定 |
| 初始化 | 宿主用 `dateRangeFromPreset("30d")` 算初始值（與元件同一套算法） |

```tsx
const [range, setRange] = useState(() => dateRangeFromPreset("30d"));
<DateRange value={range} initialPreset="30d" onChange={setRange} />
```

## 不提供日曆格

「自訂」用原生 `date` 輸入，不提供視覺化日曆格。
要視覺化日曆，先到缺件認領回報使用場景。
