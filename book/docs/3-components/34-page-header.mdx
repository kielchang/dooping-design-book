# PageHeader 頁首

**[頁面解剖](/pages/page-anatomy)第①區的元件化。** 頁首區放什麼以那一頁為準；
[頁面總覽](/pages/overview)跨頁守則的「一頁一個 h1」「至多一顆主要動作」由這個元件的預設值落實。

<StoryLink id="元件-外殼-頁首-pageheader--典型組成" />

## 三個 export，對應資訊架構的三層

| export | 用在 | 規則 |
| --- | --- | --- |
| `PageHeader` | 每一頁 | 頁首骨架。渲染整頁唯一的 h1 |
| `BackLink` | 兩層（清單 → 明細） | 真 `<a>` 的「返回清單」 |
| `Breadcrumb` | 三層以上 | 末項＝目前頁，不可點 |

`BackLink` 與 `Breadcrumb` 都放進 `PageHeader` 的 `nav` slot。
**兩層用返回、三層以上用麵包屑，不要同時放**。層級再深時修站台層的分區
（見[後台系統的資訊架構](/patterns/back-office-ia)），不要把麵包屑加長。

## 五個 slot

```tsx
<PageHeader
  nav={<BackLink href="/records" />}   // 上層路徑（BackLink 或 Breadcrumb）
  title="項目清單"                       // h1，一頁一個
  badges={<Badge variant="success">啟用中</Badge>}  // 與標題同列
  meta="共 18 筆・最後更新 2024-02-07"   // 副標一行
  actions={<Button>新增項目</Button>}    // 右側；至多一顆主要動作
/>
```

版型固定，呼叫端不調：外層 `space-y-2`，標題列固定
`flex flex-wrap items-center justify-between gap-3`。`meta` 是**一行**；長說明放內容區。

## 返回入口：一律真連結

<StoryFrame id="元件-外殼-頁首-pageheader--明細頁的返回入口" title="明細頁頁首：返回＋識別＋狀態＋動作" height={220} />

`BackLink` 渲染 `<a href>`，不是 `<button onClick={history.back}>`
（與[明細頁](/pages/detail-page)的返回入口規則相同）。

元件庫不綁路由：`href` 由宿主給、連結元件由 `renderLink` 注入（比照側欄
[SidebarNav](/components/app-shell-sidebar) 的同名注入點）。預設就是真 `<a href>`，
MPA 與文件站不必多寫；SPA 宿主注入自家的 Link，不必抄走後改原始碼，
也不必自己在 `href` 前面補部署子路徑（路由的 basename 會處理）：

```tsx
<BackLink href="/records" />   // MPA／文件站：預設真 <a href>

// SPA（react-router）：其餘 props 原樣轉發——按鈕外觀是經 asChild 合併進去的 className
const renderLink = ({ href, ...props }: PageLinkProps) => <Link to={href} {...props} />;
<BackLink href="/records" renderLink={renderLink} />
<Breadcrumb items={crumbs} renderLink={renderLink} />   // 麵包屑同一個注入點，末項不經注入
```

## 麵包屑

<StoryFrame id="元件-外殼-頁首-pageheader--三層以上用麵包屑" title="三層以上：末項是目前頁，不可點" height={200} />

```tsx
<Breadcrumb
  items={[
    { label: "基本資料", href: "/master" },
    { label: "單位", href: "/master/units" },
    { label: "甲單位" },      // 沒有 href＝目前頁
  ]}
/>
```

末項不給 `href`：它帶 `aria-current="page"` 且**不渲染成連結**。
中間層不折疊（`…`）；深到需要折疊時修分區。

## 無障礙

- h1 由元件渲染，**一頁一個**。（守衛：三支 story 的 play function 直接斷言）
- `Breadcrumb` 是 `nav` 地標，可及名稱預設「所在位置」（`label` 可覆寫）。
- 分隔符 `ChevronRight` 帶 `aria-hidden`。
- 根元素是 `<div>` 不是 `<header>`；頁首的語意由 h1 承擔。

## 組進外殼

站台外殼（[AppShell／Sidebar](/components/app-shell-sidebar)）管側欄與頂列，
`PageHeader` 管單頁的第①區。**頂列不重複頁面標題。**

## Token

零新 token。字級走[標題階層](/pages/page-anatomy)的 `text-2xl font-semibold`，
副標走 `--muted-foreground`。

## 取用

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/page-header.json
```

一個 item 帶三個 export，會自動帶入 `button` 與 `utils`。
