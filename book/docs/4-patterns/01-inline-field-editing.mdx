# 唯讀逐欄編輯

**適用**：主要是看、偶爾才改的主檔表單。每次都要全部填一遍的建立表單不適用（見下方「新增模式」）。

**預設唯讀，逐欄點開。**

```
唯讀態（像值，帶淡鉛筆）
   ↓ 點擊
編輯態（真正的輸入框，自動聚焦）
   ↓ 改值
已變更態（整欄琥珀 ＋「已變更」標籤 ＋ 還原鈕）
   ↓ Esc / blur
唯讀態（保留琥珀）
```

四個要素缺一不可：

- 唯讀態要有**可發現線索**（淡鉛筆）
- 改動要**整欄標色**
- 要有**逐欄還原**
- undo/redo **先確認舊值→新值**

搭配[送出前變更摘要](/components/change-summary)使用。

## 新增模式

新增模式關掉這個行為：`alwaysEdit` ＋ `trackChanges={false}`。

## 規則

<Rules>
  <Do>
    <p><strong>編輯／檢視是同一個畫面</strong>，只是欄位個別切換態。</p>
  </Do>
  <Dont>
    <p>不要做<strong>「檢視模式／編輯模式」全頁切換</strong>。</p>
  </Dont>
</Rules>

<Rules>
  <Do><p>改動用<strong>保留色</strong>（琥珀）標記，全站只有這一個意思。</p></Do>
  <Dont><p>不要用「儲存按鈕變亮」當唯一線索。</p></Dont>
</Rules>
