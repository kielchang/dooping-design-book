# 引導式導覽與驗收標記

**適用**：在真的畫面上帶新使用者走一遍關鍵路徑；同一個元件也用來逐步驗收。

## 做法

### 1. 聚光洞可以點穿

用巨大 spread 的 `box-shadow` 罩住洞外，洞本身透明且 `pointer-events: none`。
被圈起來的控制項要點得到。

**導引是教人操作，不是代替他操作**：不自動替使用者點下去。

### 2. 卡片可以縮小

需要實際操作時（開對話框、切分頁），卡片收成右下角小膠囊，整個畫面恢復可用。
換步時自動展開。

<Rules>
  <Do><p>提供「縮小」按鈕，而且圖示要看得懂（`−` ／ `⤢`）。</p></Do>
  <Dont><p>不要只提供「關閉」。</p></Dont>
</Rules>

### 3. 鍵盤與螢幕報讀器

- ← → 換步、Esc 略過、Enter 前進
- 每步自動把焦點移入卡片
- `aria-live="polite"` 讓報讀器唸出新內容
- `aria-modal="false"`——它**不是** modal，背景仍可操作

### 4. 錨點找不到要降級，不是壞掉

目標元素不存在時（該分頁沒開、該功能沒權限），`targetRect = null`
→ 顯示置中卡片，內容照舊。

## 延伸：同一個元件做驗收

加上「✅ 通過／❌ 有問題＋備註」的逐步標記，走完就是一份驗收報告。

## 錨點與步數

- 錨點用**語意屬性**（`data-tour="export-button"`），不用 CSS selector
- 錨點找不到時降級成置中卡，不要整支中斷
- 導覽步驟數控制在 **3–7 步**

## 規則

<Rules>
  <Do><p>導覽涵蓋<strong>一條完整的關鍵路徑</strong>（從進入到完成一件事）。</p></Do>
  <Dont><p>不要用導覽逐一介紹每個按鈕。</p></Dont>
</Rules>
