# 資料表標準

**適用**：凡是「使用者要在裡面找某一筆」的清單。

## 做法：一份欄位設定驅動全部

```tsx
{
  key: "amount",
  header: "金額",
  numeric: true,                        // 右對齊 ＋ 等寬
  cell: (r) => formatMoney(r.amount),
  sortValue: (r) => r.amount,           // 有才可排序
  filterText: (r) => String(r.amount),  // 參與關鍵字搜尋
  filter: "range",                      // 單欄篩選型態
  total: (rows) => formatMoney(sum(rows)),
  freeze: true,                         // 凍結首欄
}
```

下面這張表由上面那份設定產出——**九條標準全部由欄位設定驅動，不另外寫**：

## 九條標準

| # | 標準 |
| --- | --- |
| 1 | **關鍵字搜尋**橫跨所有文字欄 |
| 2 | **單欄篩選**：文字包含／數值範圍／多選 |
| 3 | 同欄多條件 **OR**、跨欄 **AND** |
| 4 | 排序三態：無 → 大到小 → 小到大 |
| 5 | **門檻式分頁**：沒超過一頁就不顯示分頁器 |
| 6 | **合計算篩選後全部**，不是當頁 |
| 7 | **凍結首欄** |
| 8 | **匯出跟著畫面**（篩選＋排序後） |
| 9 | 空狀態**分辨「沒資料」與「篩不到」** |

## 三種列狀態要真的分得開

「我指在哪一列」「我選了哪幾列」要一眼分得出來。淺色下相鄰狀態的色差（ΔE00）：

| 相鄰狀態 | ΔE00 |
| --- | --- |
| 一般 → hover | **3.0** |
| hover → 已選 | **7.8** |

三種狀態都疊一層 `currentColor`（6% / 14% / 20%），
「深了一階」在一般列與斑馬列上一樣成立。

兩條連帶規則：

- **已選的列，次要文字改用正文色。**
  `TableRow` 在 `data-state="selected"` 時直接把 `--muted-foreground` 重新定義成 `--foreground`。
- **多選時 checkbox 才是主要線索**，底色是輔助；顏色不是唯一線索。

門檻見[互動狀態的顏色邏輯](/foundations/color#互動狀態的顏色邏輯)。

## 加分項：十字對準與可調欄寬

- **十字對準**：指到哪一格就 highlight 整行整列。
- **可調欄寬**：拖曳邊界、雙擊自適應。
