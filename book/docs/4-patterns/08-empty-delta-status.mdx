# 空狀態、變異與狀態徽章

**適用**：空狀態、變異數字與狀態徽章。三者共用同一條規則：**顏色永遠不是唯一線索。**

## 空狀態：三種空不一樣

| 情境 | 文案要回答 |
| --- | --- |
| 還沒有資料 | 引導建立第一筆 |
| 篩選後沒結果 | 說出目前條件，引導放寬 |
| 沒有權限 | 說明原因與找誰 |

    <div className="rounded-lg border"><EmptyState compact title="沒有檢視權限" hint="此區資料僅限管理員檢視，請洽系統管理者。" /></div>

<Rules>
  <Do><p>空狀態要有<strong>下一步</strong>。</p></Do>
  <Dont><p>不要三種情境共用一句「查無資料」。</p></Dont>
</Rules>

## 變異：▲▼ ＋ 文字 ＋ 顏色

<Demo title="三重編碼">
  <div className="space-y-1 text-sm">
    <p>營收：<Delta value={128400} posLabel="增加 " negLabel="減少 " /></p>
    <p>誤差數（越少越好）：<Delta value={340} goodWhen="negative" posLabel="超出 " negLabel="短少 " /></p>
    <p>持平：<Delta value={0} /></p>
  </div>
</Demo>

元件不預設「正值＝綠色」；好壞由呼叫端以 `goodWhen` 指定（例如成本、延遲、退貨率，正值是壞消息）。

零值顯示「— 持平」，不顯示空白。

## 狀態徽章：一定要有文字

## 共同的驗收方法

**把畫面用灰階印出來**，語意還在才算做完。
