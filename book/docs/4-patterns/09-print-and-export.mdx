# 列印與匯出

**適用**：會被印出來（給主管簽名、存成 PDF 附在流程裡、寄給不用系統的人）或匯出 CSV 的頁面。

## 做法：列印規則

### 1. 底色是內容，不是裝飾

```css
@media print {
  * {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }
}
```

徽章、提示框、佔位塊靠底色辨義，列印時底色一律保留。

保底：佔位塊之類純靠底色的元素，列印時補上淡邊框。

### 2. 控制項一律隱藏

搜尋框、篩選鈕、分頁器、匯出鈕、側邊欄、導覽——印出來要是一份**乾淨文件**。

元件內建 `print-hidden` class；容器層另外隱藏站台外殼。

### 3. 不跨頁截斷

```css
@media print {
  thead { display: table-header-group; }   /* 每頁重複表頭 */
  tfoot { display: table-footer-group; }
  tr, img, svg, figure, .print-block { break-inside: avoid; }
  h1, h2, h3, h4 { break-after: avoid; }   /* 標題不孤懸頁底 */
  p { orphans: 3; widows: 3; }             /* 段落至少留 3 行 */
}
```

可能超過一頁的大區塊，不能只靠整塊 `break-inside: avoid`，要自己再細分（例如逐步驟各自 avoid）。

### 4. 黏性元素要解除

```css
@media print { .sticky-header { position: static !important; } }
```

表頭重複交給 `table-header-group` 處理。

### 5. 動畫改印靜態版本

```css
@media print {
  .spotlight-ring {
    animation: none !important;
    box-shadow: 0 0 0 3px hsl(var(--primary)), 0 0 0 6px hsl(var(--primary) / 0.3) !important;
  }
}
```

**換成靜態版本**，不要只寫 `animation: none`。

### 6. 頁面邊界與頁首頁尾

```css
@media print {
  @page { margin: 14mm 12mm 16mm; }
}
```

邊界一律自己定，不用瀏覽器預設。下緣留得比上緣多，放頁尾。

頁首（文件名稱、期間、產生時間）與頁尾（頁碼、系統版本）**只在列印時出現**。
做法是先無條件隱藏，再在 `@media print` 內開啟：

```css
/* 基礎規則：螢幕上一律不顯示 */
.print-header,
.print-footer { display: none; }

/* 列印時才打開 */
@media print {
  .print-header,
  .print-footer { display: block; }
}
```

<Rules>
  <Do><p>基礎規則（隱藏）與 media 區塊（顯示）<strong>要分開寫</strong>，
  而且隱藏那條要在前面。</p></Do>
  <Dont><p>不要只在 <code>@media print</code> 裡寫顯示規則、卻忘了寫螢幕上的隱藏規則。</p></Dont>
</Rules>

頁尾用固定定位貼在頁底，放**系統版本 ＋ commit ＋ 產生時間**：

```
月度彙總表　v1.4.2 · a3f9c21　2026-07-29 14:20 產生
```

版本字串要與畫面上其他地方**同一個來源**，做法見
[版本策略](/governance/versioning)。

### 7. 版面高度要回歸內容

```css
@media print {
  html, body, #root, .app-shell {
    height: auto !important;
    min-height: 0 !important;
  }
}
```

應用外殼的 `min-height: 100vh` 在列印時一律解除。

### 8. 印不出來的內容要誠實標示

嵌入的互動範例、影片、地圖、需要展開才有內容的元件，在紙上印不出來。
不印空白框、不直接隱藏，一律**換成替代說明框**：

```css
@media print {
  .embed-frame  { display: none !important; }
  .embed-print-note { display: block !important; border: 1px dashed; }
}
```

<Rules>
  <Do><p>替代框要說出<strong>那裡原本是什麼</strong>，以及<strong>去哪裡看得到</strong>。</p></Do>
  <Dont><p>不要印一個空的容器。</p></Dont>
</Rules>

### 9. 摺疊與輪播，列印時全部展開

會自動輪播的步驟示意、預設收合的明細、分頁的內容——
螢幕上一次只顯示一份，**紙上必須全部都在**。

```css
/* 螢幕：只顯示當前步 */
.step { display: none; }
.step.is-active { display: block; }

@media print {
  .step { display: block !important; break-inside: avoid; }
  .step .step-caption { display: block !important; }  /* 各步字幕一起印 */
  .carousel-controls,
  .carousel-counter { display: none !important; }     /* 控制項與「3 / 5」計數失義 */
}
```

三個細節：

1. **全部步驟要在 DOM 裡**，只用 CSS 控制顯隱，不要用條件渲染只掛當前步。
2. **各步的字幕要一起印出來**，每一步都帶自己的說明。
3. **計數器（「3 / 5」）要隱藏**。

<Rules>
  <Do><p>把螢幕上的「展開全部」按鈕做成<strong>與列印共用同一套展開樣式</strong>。</p></Do>
  <Dont><p>不要為列印另寫一套展開邏輯。</p></Dont>
</Rules>

### 10. 外連箭頭要拿掉

外連連結後面用 `::after` 加的箭頭圖示，列印時拿掉：

```css
@media print { a[target="_blank"]::after { content: ""; } }
```

## 匯出（CSV）

- **加 UTF-8 BOM**
- **匯出＝目前畫面**（篩選＋排序後）
- 跳脫引號、逗號、換行
- **公式開頭的文字補 `'`**（`=` `+` `-` `@`、Tab、CR 開頭）；數字與純數字文字不補，匯出後仍能計算
- 檔名帶語意（`orders-2024-02.csv`）

## 平台自己做的匯出：照畫面的呈現方式

設計規範管畫面上的表格與圖表怎麼呈現；保留格式的 Excel、報表檔、圖表圖片**由平台自己實作**。
照下面兩張表做，匯出檔讀起來才會跟畫面一樣。

### 表格

| 畫面上 | 匯出檔裡 |
| --- | --- |
| 列＝目前畫面（篩選＋排序後的全部列） | 一樣。取 DataTable `toolbar` 函式給的 `rows`，不要自己重算（見 [DataTable](/components/data-table)「分頁、合計、匯出」） |
| 欄的順序與欄名 | 跟畫面相同 |
| 數字欄（靠右、千分位） | 存成**數字**，不存文字；靠右；千分位（Excel 格式 `#,##0`） |
| 金額 | 存成數字，格式帶同一個幣別符號（`"$"#,##0`） |
| 百分比（預設 1 位小數） | 存比例值（`0.125`），格式 `0.0%` |
| 日期（`YYYY-MM-DD`） | 存成**日期**，格式 `yyyy-mm-dd` |
| 狀態徽章 | 只寫文字標籤（例如「已確認」），不靠底色傳達意思 |
| 被截斷的長文字（…） | 寫完整文字 |
| 表頭、凍結的首欄 | 表頭列粗體並凍結；畫面上首欄有凍結的，匯出檔也凍結 |
| 合計列（算篩選後全部） | 放最後一列、粗體，數值跟畫面相同 |
| 斑馬紋、十字對準、滑鼠移上去的效果 | 不帶——這些是畫面上的閱讀輔助 |

### 圖表

| 畫面上 | 匯出檔、圖片或報表裡 |
| --- | --- |
| 圖種（[Charts](/components/charts)「何時用哪種圖」、不提供圓餅圖） | 用同一種圖；畫面上不用圓餅圖，匯出也不用 |
| 序列色 1～8 | 取 `@dooping/tokens/tokens.json` 裡 `chart.light` 的色碼，照順序用（六種主題共用同一組） |
| 配色三層：語意 → 身分 → 區辨 | 同一套判斷：狀態類的維度用狀態色（`color.light` 的 `success-subtle` 等，跟畫面同一組）；反覆出現的維度，同一個項目永遠同一個顏色；一次性的比較照順序取色 |
| 超過 8 類彙總成「其他（N 項）」 | 一樣先彙總，不重複用色 |
| 直接把數值標在圖上 | **一定要標**：匯出檔沒有滑鼠提示可以看數字 |
| 圖例有文字 | 一樣；另外把標題、單位、資料期間寫在圖上——匯出後就離開了原本的頁面 |
| 數字格式 | 跟表格同一套（千分位、百分比位數） |
| 旁邊拿得到數字本身 | 同一份資料一起匯出（例如放在另一張工作表），數字不能只存在圖裡 |
| 空資料、只有一筆、全部是零 | 照畫面上的文字說明處理，不輸出一張空白的圖 |
| 主題與深淺模式 | **一律用淺色模式的值（白底）**：匯出檔常被印出來、貼進報告，白底在哪裡都讀得清楚 |

## 共用列印樣式

列印規則做進 **token 層的 CSS**（`.print-hidden`、`.print-block`、`.print-only`），
預設就對，不要每頁各寫一份 `@media print`。

## 跟隨主題 vs 強制白底

深色模式下列印，「跟隨當下主題」與「強制白底」選一種，不能兩者各做一半：

<Rules>
  <Do><p>選一種，並且<strong>整層一致</strong>。要強制白底，就把表面 token
  在列印時整組換成淺色；要跟隨主題，就讓 <code>print-color-adjust: exact</code> 涵蓋全部元素。</p></Do>
  <Dont><p>不要只把 <code>body</code> 改成白色而不動元件底色。</p></Dont>
</Rules>

無論選哪一種，**靠底色辨義的元素都要補一層保底邊框**：

```css
@media print { .placeholder, .badge { border: 1px solid; } }
```
