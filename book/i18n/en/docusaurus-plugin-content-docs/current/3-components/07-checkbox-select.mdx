## When not to use Select

<Rules>
  <Do><p>Use Select for <strong>six or more</strong> options, or when options change dynamically.</p></Do>
  <Dont><p>For 2–5 short, fixed labels, use <a href="/components/seg-group">SegGroup</a>. Select requires two clicks (open, choose) before all options are visible; a segmented group is visible and complete in one click.</p></Dont>
</Rules>

For multiple selection, use [Chips](/components/chips), not a multi-select dropdown. After choosing, users should still be able to see what they chose; losing that visibility is one of the most common admin complaints.

## A Checkbox always needs a Label

`<Label htmlFor>` makes the text clickable too, which is especially important on touch devices (a 16px box versus an entire row).
