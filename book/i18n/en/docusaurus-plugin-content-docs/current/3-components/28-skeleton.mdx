# Skeleton

On first load, use gray blocks that preserve the **shape of the real layout**.

## Rules

<Rules>
  <Do><p>Skeletons <strong>preserve the height and shape of the real layout</strong> so the page does not jump when loading completes. That is their only reason to exist.</p></Do>
  <Dont><p>Do not throw in three equal gray bars. A skeleton that does not match the real content makes the whole page jump, worse than “Loading…” text.</p></Dont>
</Rules>

<Rules>
  <Do><p>Use it only for<strong> first load</strong>.</p></Do>
  <Dont><p>Do not replace existing content with skeletons during refresh. Keep the readable old content and swap in new data when it arrives.</p></Dont>
</Rules>

## Accessibility and motion

- Skeletons are `aria-hidden`; put `aria-busy="true"` on the **container** and remove it when complete. Screen readers do not need to read gray bars.
- Pulse respects `prefers-reduced-motion` (`motion-reduce:animate-none`); a still gray block communicates “not ready.”

## Install

```bash
npx shadcn@latest add https://kielchang.github.io/dooping-design-book/r/skeleton.json
```

`Skeleton` is one shape-customizable block; dimensions come from classes. `SkeletonText` renders n lines, with a 60% last line so the paragraph looks real.
