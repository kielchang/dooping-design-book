陰影與層次

陰影是表面抬升的層級，不是裝飾。所以只有 3 階。

Token意思用在哪
shadow-sm貼地卡片、輸入框
shadow-md抬起下拉選單
shadow-lg浮起對話框、導引卡
三階陰影
sm
md
lg

深色模式靠表面亮度分層，不靠陰影​

深色背景上的陰影本來就幾乎看不見。所以深色模式的層次來自表面亮度：

background (8%)  <  card (12%)  <  popover (15%)  <  muted (18%)  <  border (22%)

這也是為什麼深色 token 不是淺色的機械式反轉。反轉出來的深色介面， background 和 card 會變成同一個值，整個介面扁平到分不出哪一塊是浮起來的。

深色的五級表面（把文件切到深色模式看差異）
--background頁面底
--card卡片
--popover浮層
--muted弱化區塊

z-index 分層​

沒有把 z-index 做成 token，但有約定：

範圍用途
10黏性表頭、凍結首欄
50下拉／對話框／浮層
55–60表格欄位篩選面板（要蓋過凍結首欄）
200引導聚光層（要蓋過一切）

刻意留大間隔：需要插一層時不用重排全部。
